# AZ-500 Readiness Checklist

## Current Information

- [ ] I checked the official study guide for objective changes.
- [ ] I understand that AZ-500 retires on 31 August 2026.
- [ ] I confirmed that my planned exam date is before retirement.
- [ ] I reviewed Microsoft's exam policy, sandbox, and identification requirements.

## Hands-On Capability

- [ ] I can distinguish Azure roles, Entra roles, control plane, and data plane.
- [ ] I can implement PIM, MFA, Conditional Access, and emergency-access monitoring.
- [ ] I can secure applications with managed identities and least privilege.
- [ ] I can reason about NSGs, routing, private endpoints, private DNS, Firewall, WAF, and DDoS.
- [ ] I can secure VM, container, storage, SQL, Key Vault, encryption, backup, and recovery paths.
- [ ] I can assign and troubleshoot Azure Policy and Defender for Cloud recommendations.
- [ ] I can explain Defender plans, Sentinel connectors, analytics, incidents, and safe automation.

## Decision Quality

- [ ] I can explain why one control fits better than another.
- [ ] I test allowed and denied paths.
- [ ] I include evidence, monitoring, rollback, cost, and operational ownership.
- [ ] I distinguish posture findings from active threat detections.
- [ ] I know when to use official documentation instead of relying on memory.

## Integrity

- [ ] I am using official resources, authorised labs, and original practice materials.
- [ ] I am not using or sharing exam dumps or recalled live questions.
