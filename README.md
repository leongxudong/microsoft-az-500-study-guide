# Microsoft AZ-500 Study Guide and Hands-On Labs

> **Status: RETIRED STUDY ARCHIVE**  
> Microsoft retired AZ-500 and the Azure Security Engineer Associate certification on 31 August 2026. This repository is retained for historical learning value and transferable Azure security foundations; it is not an active certification project or current portfolio centerpiece.

Community learning materials for **Exam AZ-500: Microsoft Azure Security Technologies** and the former **Microsoft Certified: Azure Security Engineer Associate** path.

Use this archive for transferable Azure security concepts such as identity, Key Vault, network security, workload protection, posture management and monitoring. Learners pursuing current Microsoft cloud-security credentials should verify the active certification path and objectives on Microsoft Learn.

## What the Archive Covers

- Azure identity, access, applications, and managed identities.
- Private and public network controls.
- Compute, storage, databases, secrets, keys, and backups.
- Azure Policy, Microsoft Defender for Cloud, and Microsoft Sentinel.
- Security decisions framed through risk, compliance, and operational trade-offs.
